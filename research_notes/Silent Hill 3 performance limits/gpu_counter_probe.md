### Inferences

Selected metrics and interpretation, grounded in pinned G31 definitions:

| Metric | Raw meaning | Valid comparison |
| --- | --- | --- |
| `MaliGPUActiveCy` | Top-level cycles with pending queued work, including memory wait | Divide by measured interval and verified GPU clock; pending load, not useful ALU progress |
| `MaliTilerActiveCy` | Cycles tiler has queued workload | Compare to GPU-active cycles in same top-level domain; parallel with shader work |
| `MaliFragActiveCy` | Sum of fragment endpoint cycles, including fixed-function front/back ends | Divide by actual core count for aggregate per-core comparison; includes more than programmable work |
| `MaliCoreActiveCy` | Programmable-core cycles with any active warp | Compare with fragment endpoint and GPU pending work; not functional-unit occupancy |
| `MaliEngInstr` | Per-warp instruction issues; single-cycle issue, documented G31 ALU-issue-cycle alias | `EngInstr/CoreActive` matches G31 library ALU-utilization derivation; no FLOPS inference |
| `MaliTexFiltIssueCy` | Texture filtering issue cycles, including cost of complex filters | `TexFiltIssueCy/CoreActive` matches library texture-utilization derivation; concurrent with ALU |
